HDR Switch is installed and is now in your menu bar.

If your monitor isn't in HDR Switch's database, the app tells you when it starts. HDR and the color profile still work, but local dimming and brightness don't until you add it: click the menu bar icon, choose Settings…, then Detect Monitor….

If you chose the command line tool, hdrctl is in ~/.local/bin. Add that folder to your PATH to run it from Terminal.
